Copy `env.example` to `.env`. Names and obtain links: `docs/API_KEYS.md`.

- RPC: `GROKDESK_RPC` or `--rpc`
- Axiom: `AXIOM_ACCESS_TOKEN` `AXIOM_REFRESH_TOKEN` — https://axiom.trade
- Photon: terminal https://photon-sol.tinyastro.io/ — no official API key
- Jito: `JITO_BLOCK_ENGINE_URL` `JITO_UUID` — https://docs.jito.wtf/lowlatencytxnsend/

Wallet by screen hand-off. Public address only in desk.md. Require Approval for financial actions. Never commit `.env`.
